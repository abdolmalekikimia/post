# EPS-201: تست End-to-End به‌روزرسانی خودکار Imageها در Edge Installer

> **تیم:** P  |  **اولویت:** Medium  |  **نوع:** Task  |  **نسخه اصلاح‌شده Installer:** `v2.7.1`  |  **محیط‌های بررسی‌شده:** `192.168.10.190` و `192.168.10.114`

---

## 🎯 هدف و شرح تسک

ثبت و تثبیت اصلاح قابلیت **Auto Update** در نسخه **v2.7.1** نرم‌افزار Edge Installer و تحویل سناریوی تست کامل End-to-End (E2E) به تیم تست.

### 📌 شرط تأیید نهایی (DoD):
این تسک زمانی **تأیید نهایی** می‌شود که سناریوی تست **از صفر (from scratch)** با **انتشار واقعی یک Image جدید در مخزن Nexus** توسط تیم تست اجرا و رفتار خودکار اینستالر بررسی شود.

---

## 📋 سناریوهای آزمون End-to-End (BDD)

| شناسه | عنوان سناریو | هدف آزمون | معیار قبولی (Pass Criteria) |
|-------|-------------|-----------|-----------------------------|
| **TC-01** | صحت نسخه Installer و آدرس سرورها | اعتبارسنجی نسخه نصاب (`>= v2.7.1`) و هاست‌های مجاز (`192.168.10.190`, `192.168.10.114`) | نسخه نصاب و هاست‌ها بدون مغایرت تایید شوند. |
| **TC-02** | تشخیص انتشار Image جدید در Nexus | استعلام مانیفست OCI و هش SHA256 از رجیستری Nexus | دریافت مانیفست معتبر با Digest و تگ نسخه جدید. |
| **TC-03** | به‌روزرسانی نود اصلی (`192.168.10.190`) | پول خودکار ایمیج و بازسازی Graceful کانتینر در نود ۱ | کانتینر با تگ جدید اجرا شود و دیتابیس خراب نشود. |
| **TC-04** | هماهنگی به‌روزرسانی نود ثانویه (`192.168.10.114`) | اعمال اتواپدیت متوازن روی نود ۲ بدون قطعی عملیات سورتینگ | نود ۲ نیز با موفقیت ایمیج جدید را اجرا کند. |
| **TC-05** | بررسی سلامت بعد از آپدیت و پایداری دیتابیس | فراخوانی Health Check (پاسخ HTTP 200) و عدم حذف جداول SQLite و Volumes | پایداری دیتابیس محلی تایید و سلامت سرویس OK باشد. |
| **TC-06** | اعتبارسنجی بازگشت خودکار (Rollback) | در صورت خرابی استارت کانتینر جدید، اینستالر نسخه قبلی را بازگرداند | بازگشت موفق به تگ پایدار قبلی (`v2.7.0`). |

## 🚀 راهنمای اجرای تست برای تیم QA و تیم P

### ۱. اجرای تست‌های یونیت مستقل (بدون نیاز به سرور و نکسوس)
```powershell
python -m pytest tests/unit/test_eps201_core.py -v
```

### ۲. اجرای تست E2E لایو (با انتشار واقعی در مخزن Nexus)
پس از بیلد ایمیج جدید و Push آن به Nexus:
```powershell
# ۱. تنظیم متغیرهای محیطی برای اجرای E2E
$env:RUN_INSTALLER_E2E="1"
$env:INSTALLER_VERSION="v2.7.1"
$env:NEXUS_REGISTRY_URL="http://nexus.post.ir:8081/repository/docker-registry"
$env:INSTALLER_PRIMARY_HOST="192.168.10.190"
$env:INSTALLER_SECONDARY_HOST="192.168.10.114"

# ۲. اجرای آزمون E2E به‌روزرسانی خودکار
python -m pytest tests/installer/test_eps201_autoupdate.py -v
```
