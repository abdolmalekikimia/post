# Security and Public-Sanitization Boundary

This repository is intentionally a sanitized portfolio representation. It is
not an authorized client for any production or internal system.

Do not submit:

- passwords, access tokens, API keys, cookies, JWTs, or connection strings;
- internal hostnames, private IPs, company URLs, or device identifiers;
- internal ticket IDs, business documents, or production request/response data.

Use the example configuration files and reserved placeholder values for local
demonstrations. If sensitive information is found, remove it from the working
tree, revoke or rotate the credential, and review Git history before publishing
another version.
